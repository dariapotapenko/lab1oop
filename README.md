# Лабораторна робота №1: «Електронні таблиці»

MAUI-застосунок для введення, перевірки та обчислення виразів у клітинках електронної таблиці.

## Варіант роботи

Варіант 80 використовує такі групи операцій:

- **Функції:** `mmax(x1, x2, ...)`, `mmin(x1, x2, ...)`;
- **Порівняння:** `=`, `<`, `>`;
- **Логічні операції:** `not`, `and`, `or`, `eqv`.

У виразах можна використовувати цілі числа довільної довжини, круглі дужки та посилання на клітинки, наприклад `A1` або `B12`.

## Можливості програми

- введення формул у клітинки таблиці;
- посилання на інші клітинки;
- автоматичне обчислення залежних виразів;
- перевірка синтаксису перед обчисленням;
- повідомлення про помилки у формулах;
- виведення початкових виразів або обчислених значень;
- додавання та видалення рядків і стовпців;
- створення нової таблиці;
- збереження таблиці у форматі JSON та відкриття збереженого файлу;
- довідка та інформація про програму.

## Синтаксис виразів

Формулу можна вводити з початковим знаком `=` або без нього:

```text
=mmax(A1, A2, 10)
=mmin(25, A1, A2)
=A1 < A2
=not (A1 = A2)
=A1 < A2 and A2 > 0
=A1 < A2 or A1 = A2
=A1 < A2 eqv A2 > A1
```

Назви функцій та логічних операторів підтримуються у нижньому або верхньому регістрі. Значення клітинок можуть бути числами або логічними результатами інших виразів.

## Обробка помилок

Застосунок виконує два етапи обробки формули:

1. перевіряє лексичну та синтаксичну правильність виразу;
2. обчислює його значення з урахуванням посилань на клітинки.

Користувач отримує повідомлення, якщо формула має неправильний синтаксис, містить недопустиму операцію, посилається на клітинку з помилкою або утворює циклічну залежність.

## Структура проєкту

- `SpreadsheetLab.Ui` — основний .NET MAUI-проєкт;
- `SpreadsheetLab.Ui/Parsing` — граматика ANTLR та відвідувач для обчислення виразів;
- `SpreadsheetLab.Ui.Tests` — три MSTest-тести для перевірки обчислень;
- `SpreadsheetLab.Ui.sln` — solution для відкриття у Visual Studio або VS Code.

## Використані технології

- C#;
- .NET 7;
- .NET MAUI;
- ANTLR 4.13.1;
- MSTest.

## Запуск

1. Відкрийте папку репозиторію у Visual Studio Code або Visual Studio.
2. Відкрийте solution `SpreadsheetLab.Ui/SpreadsheetLab.Ui.sln`.
3. Відновіть залежності:

   ```bash
   dotnet restore SpreadsheetLab.Ui/SpreadsheetLab.Ui.sln
   ```

4. Запустіть потрібну платформу через Visual Studio або команду .NET MAUI. Наприклад, для Mac Catalyst:

   ```bash
   dotnet build SpreadsheetLab.Ui/SpreadsheetLab.Ui.csproj \
     -f net7.0-maccatalyst \
     -p:RuntimeIdentifier=maccatalyst-arm64 \
     -p:ValidateXcodeVersion=false
   ```

На Windows для запуску потрібен встановлений workload .NET MAUI та відповідний Windows SDK.

## Запуск тестів

```bash
dotnet test SpreadsheetLab.Ui.Tests/SpreadsheetLab.Ui.Tests.csproj
```

Тестовий проєкт перевіряє функції `mmax` і `mmin`, логічні операції та повторний розрахунок формули після зміни значення клітинки.
