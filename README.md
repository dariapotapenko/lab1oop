# Лабораторна робота №1: «Електронні таблиці»

MAUI-застосунок для введення, перевірки та обчислення виразів у клітинках електронної таблиці.

## Варіант роботи

Варіант 80 використовує такі групи операцій:

- **Функції:** `mmax(x1, x2, ...)`, `mmin(x1, x2, ...)`;
- **Порівняння:** `=`, `<`, `>`;
- **Логічні операції:** `not`, `and`, `or`, `eqv`.

У виразах можна використовувати цілі числа довільної довжини, круглі дужки та посилання на клітинки, наприклад `A1` або `B12`.

## Можливості програми

- введення формул у клітинки таблиці;
- посилання на інші клітинки;
- автоматичне обчислення залежних виразів;
- перевірка синтаксису перед обчисленням;
- повідомлення про помилки у формулах;
- виведення початкових виразів або обчислених значень;
- додавання та видалення рядків і стовпців;
- створення нової таблиці;
- збереження таблиці у форматі JSON та відкриття збереженого файлу;
- довідка та інформація про програму.

## Синтаксис виразів

Формулу можна вводити з початковим знаком `=` або без нього:

```text
=mmax(A1, A2, 10)
=mmin(25, A1, A2)
=A1 < A2
=not (A1 = A2)
=A1 < A2 and A2 > 0
=A1 < A2 or A1 = A2
=A1 < A2 eqv A2 > A1
```

Назви функцій та логічних операторів підтримуються у нижньому або верхньому регістрі. Значення клітинок можуть бути числами або логічними результатами інших виразів.
